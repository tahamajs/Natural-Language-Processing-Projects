\section{Pipeline Design}
The Q1 system follows this deterministic flow:
\begin{enumerate}
\item Dataset loading and OCR-aware text extraction
\item Chunking and metadata assignment
\item TF-IDF index build and persistence
\item Query rewrite, intent classification, metadata extraction
\item Retrieval, reranking, and evidence-grounded response generation
\item Timing capture and benchmark export
\item Live RAGAS evaluation with OpenAI
\item Plot generation for report publication
\end{enumerate}
